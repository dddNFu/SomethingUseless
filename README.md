# 歌词时间偏移校准

你是否曾因为音乐和歌词对不上而烦恼？我用 `C`/`C++` 做了一个 **lrc** 歌词时间偏移校准的程序——

## 使用方法

下载可执行文件并运行，按照提示语输入即可。因本地编译器不支持中文，所以提示语使用英文。

> Drop your file here in the window.

将（歌词）文件拖放到此窗口。

> Enter the starting time of the first lyric. (eg: 00:01.14)

输入第一句歌词的起始时间。（例：`00:01.14`）

程序会将所有歌词向前（或向后）调整相同的时间，使第一句歌词的时间与你输入的时间相同。若原文件名为 `xxx.lrc`，生成的新文件名为 `xxx1.lrc`，且与原文件在同一目录下。

## 格式

两个数字+半角冒号+两个数字+半角点+两个数字，即 `mm:ss.xx`，表示 mm 分钟 ss 秒 xx0 毫秒时刻。

## 注意事项

仅支持 `lrc` 格式，但**暂不支持增强 `lrc` 格式**及其它格式。
